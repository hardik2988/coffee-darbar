# ☕ Coffee Darbar

**Where every cup gets the royal treatment.**

Coffee Darbar is a concept café website built for the **AI Foundations & Ethical AI — Cafe Project (PBL)** at UPES Dehradun, Semester 1, 2026–27.

🔗 **Live site:** https://hardik2988.github.io/coffee-darbar/

## Pages
| Page | What it does |
|---|---|
| Home | 3D cup carousel, signature lineup, AI mood recommender with a "Why this pick?" explainability card |
| Menu | Full coffee collection, search, Mindful & Ethical filters, Build-Your-Own coffee engine |
| Order | Cart with a daily caffeine meter (400 mg/day guideline), GST and pickup time |
| Reservations | 3D floor plan with live seat availability and a reservation pass |
| Coffee Passport | Five coffee origins with flavour radar and collectible stamps |
| Darbar AI | Coffee co-pilot chat (front-end demo) |
| About · Contact · Dashboard · Privacy · Terms · 404 | Supporting pages |

## Tech
HTML5 · CSS3 · Vanilla JavaScript · Bootstrap 5 · Three.js · GSAP · Lenis

No backend and no database. Cart, reservations and preferences are saved only in the visitor's own browser (localStorage).

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
npx serve .
```
